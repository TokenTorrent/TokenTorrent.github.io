红队测试与安全审计

面向数字智能体与具身机器人的对抗性安全测试

在智能体部署到生产环境之前，识别并修复其安全脆弱性。TokenTorrent 提供系统化的红队测试与安全审计服务，扎根于自研攻击研究成果，覆盖视觉理解、语言推理、行动决策等多模态攻击面，并针对发现的脆弱性提供可落地的联合防御方案。

核心能力

  • 对抗性攻击评估 — 系统化测试智能体在各类对抗性输入下的安全边界，覆盖模式诱导、上下文操纵、权威伪装、隐蔽内容注入等多种攻击范式
  • 多模态攻击面覆盖 — 视觉扰动、恶意文本注入、音频操纵等端到端攻击验证，评估从感知到决策的全链路稳健性
  • 防护能力审计 — 客观评估现有安全防御机制的实际有效性，识别单点依赖与防护盲区
  • 联合防御方案 — 基于攻击研究成果输出可组合、可度量的防御策略，而非泛泛的安全建议
  • 安全合规报告 — 输出可操作的安全改进建议与监管合规性评估

代表性子项目

  • VisionEvader — 针对视觉语言模型（VLM）的黑盒逃逸攻击研究平台。覆盖 ICL 模式诱导、视觉扰动、欺骗性文本叠加等攻击范式，组合攻击达 100% 逃逸成功率，零像素修改场景下亦可达 31%。揭示 VLM 内容审核作为独立安全机制的不足。
  • ICL-Evader — 针对语言模型 In-Context Learning 的零查询黑盒逃逸攻击框架（WWW 2026）。无需模型访问、无需查询预算即可突破 LLM 安全推理边界，同时提供可组合的联合防御策略：警示注入 + 随机模板 + 对抗样本硬化，覆盖主流开源模型。
