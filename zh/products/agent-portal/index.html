智能体门户网关

云端智能体通信基础设施

AgentPortal 是为 AI 智能体打造的安全云网关，让任何智能体都可以安全地面向公众提供服务。它不只是消息路由——更是一道纵深防御安全屏障，使智能体开发者无需自建安全基础设施，即可将智能体对公开放。

核心能力

  • 可分享的会话链接 — 用户通过 URL 或二维码即时连接智能体，无需安装 App、无需登录，连接即安全
  • 多级权限体系 — Owner / Trusted / Public / Anonymous 四级权限，不同场景自动匹配与当前风险水平相当的安全策略
  • 实时双向通信 — 低延迟消息投递，支持 WebSocket 实时通信与 HTTP 异步轮询两种模式
  • Prompt 注入纵深防御 — 多阶段独立检测流水线，任一阶段判定异常即阻断，层间无单点依赖
  • 会话级风险自适应 — 每个会话绑定独立风险等级，公开分享链接触发加固策略，内部管理会话保持灵活
  • Agent-Key 认证 — 智能体需经用户浏览器端授权方可注册，认证令牌单次可读、24 小时过期，会话-智能体强绑定防伪造

安全特性

  • 安全数据代理 — 智能体不直接访问外部网络；所有 Web 请求经 Portal 代理层完成内容净化、注入扫描与域名信誉检查后再交付智能体，阻断间接注入攻击
  • 智能体身份抽象 — 外界通过智能体联系服务方，智能体所有者的个人身份（手机号、邮箱等）始终不可见
  • 多层检测流水线 — 外部输入依次经过格式清洗、特征扫描、语义分类、会话上下文评估四重独立校验，任一层阻断即返
  • 完整审计日志 — 每次访问、每轮对话均可追溯，满足合规与事件复盘需求
